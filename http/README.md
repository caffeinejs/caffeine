# @caffeinejs/http

HTTP for CaffeineJS applications, on a web-standards engine: controllers, routes, validation and errors. The Node
application, `createWebApplication()` from `@caffeinejs/http/node`, listens on a node:http, node:https or node:http2
server. The fetch application, `createWebApplication()` from `@caffeinejs/http`, answers `app.fetch` on Bun, Deno and
workers.

```sh
npm install -E @caffeinejs/http
```

Documentation: [ai/docs/http.md](https://github.com/caffeinejs/caffeine/blob/main/ai/docs/http.md).

Install every `@caffeinejs/*` package at the same exact version: [Versioning](https://github.com/caffeinejs/caffeine/blob/main/docs/versioning.md).
