# @caffeinejs/testing

Test helpers for CaffeineJS applications: a test container for `@caffeinejs/di`, with HTTP helpers under
`@caffeinejs/testing/http` and TLS helpers under `@caffeinejs/testing/tls`.

```sh
npm install -E -D @caffeinejs/testing
```

Install every `@caffeinejs/*` package at the same exact version: [Versioning](https://github.com/caffeinejs/caffeine/blob/main/docs/versioning.md).
