# @caffeinejs/fetchy

A declarative HTTP client for CaffeineJS: a class written with TC39 decorators describes the requests, and fetchy
makes them. Transports such as `@caffeinejs/fetchy-undici` plug in beneath it.

```sh
npm install -E @caffeinejs/fetchy
```

Install every `@caffeinejs/*` package at the same exact version: [Versioning](https://github.com/caffeinejs/caffeine/blob/main/docs/versioning.md).
