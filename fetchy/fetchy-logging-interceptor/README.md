# @caffeinejs/fetchy-logging-interceptor

An interceptor for `@caffeinejs/fetchy` that logs every request and response. A Pino logger is under
`@caffeinejs/fetchy-logging-interceptor/pino`.

```sh
npm install -E @caffeinejs/fetchy-logging-interceptor
```

Install every `@caffeinejs/*` package at the same exact version: [Versioning](https://github.com/caffeinejs/caffeine/blob/main/docs/versioning.md).
