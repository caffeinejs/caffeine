# @caffeinejs/application

The application framework of CaffeineJS, on the `@caffeinejs/di` container: configuration, features, health checks,
logging, schemas and graceful shutdown. Each part has its own import, such as `@caffeinejs/application/config` or
`@caffeinejs/application/logger/pino`.

```sh
npm install -E @caffeinejs/application
```

Install every `@caffeinejs/*` package at the same exact version: [Versioning](https://github.com/caffeinejs/caffeine/blob/main/docs/versioning.md).
