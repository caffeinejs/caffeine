# @caffeinejs/multipart

Multipart form handling (`multipart/form-data`), file uploads included, for a CaffeineJS HTTP application.

```sh
npm install -E @caffeinejs/multipart
```

Install every `@caffeinejs/*` package at the same exact version: [Versioning](https://github.com/caffeinejs/caffeine/blob/main/docs/versioning.md).
