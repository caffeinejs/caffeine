# @caffeinejs/brewer

An HTTP client typed end to end with a CaffeineJS application. It calls the server over the network, or a running
application in process, such as one a test starts.

```sh
npm install -E @caffeinejs/brewer
```

Install every `@caffeinejs/*` package at the same exact version: [Versioning](https://github.com/caffeinejs/caffeine/blob/main/docs/versioning.md).
