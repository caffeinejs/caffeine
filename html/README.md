# @caffeinejs/html

JSX server-side rendering for a CaffeineJS HTTP application, with `@kitajs/html` as the JSX runtime: a handler
returns JSX, and the response is HTML.

```sh
npm install -E @caffeinejs/html
```

Install every `@caffeinejs/*` package at the same exact version: [Versioning](https://github.com/caffeinejs/caffeine/blob/main/docs/versioning.md).
