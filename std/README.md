# @caffeinejs/std

Dependency-free utilities every CaffeineJS package shares: durations, byte sizes and error messages. It has no root
import: import from `@caffeinejs/std/duration`, `@caffeinejs/std/bytes` or `@caffeinejs/std/err`.

```sh
npm install -E @caffeinejs/std
```

Install every `@caffeinejs/*` package at the same exact version: [Versioning](https://github.com/caffeinejs/caffeine/blob/main/docs/versioning.md).
