# @caffeinejs/openapi

OpenAPI documents for a CaffeineJS HTTP application, generated from its routes, with a UI to browse them.

```sh
npm install -E @caffeinejs/openapi
```

Install every `@caffeinejs/*` package at the same exact version: [Versioning](https://github.com/caffeinejs/caffeine/blob/main/docs/versioning.md).
